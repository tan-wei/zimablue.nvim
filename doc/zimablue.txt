INTRODUCTION                                                *zimablue-introduction*

zimablue.nvim is a dark Neovim colorscheme inspired by the iconic Zima Blue
color from Love, Death & Robots.

The canonical accent color is #5BC2E7.

===============================================================================
USAGE                                                               *zimablue-usage*

Load the default variant: >lua

  vim.cmd.colorscheme("zimablue")

<
Load a specific variant directly: >vim

  colorscheme zimablue-sunset
  colorscheme zimablue-pool
  colorscheme zimablue-volcano
  colorscheme zimablue-storm

<
===============================================================================
CONFIGURATION                                               *zimablue-configuration*

Call setup before loading the colorscheme: >lua

  require("zimablue").setup({
    transparent = false,
    terminal_colors = true,
    dim_inactive = false,
    italic = true,
    bold = true,
  })

  vim.cmd.colorscheme("zimablue")

<
Available options: >lua

  {
    variant = "default",      -- default, sunset, pool, volcano, storm
    transparent = false,      -- disable background colors
    terminal_colors = true,   -- set g:terminal_color_0 through _15
    dim_inactive = false,     -- dim inactive windows
    italic = true,            -- default italic style for comments/keywords
    bold = true,              -- default bold style for selected groups
    styles = {},              -- syntax style overrides
    on_colors = function(colors) end,
    on_highlights = function(highlights, colors) end,
  }

<
The `variant` option is used when loading the default colorscheme entrypoint: >lua

  require("zimablue").setup({ variant = "pool" })
  vim.cmd.colorscheme("zimablue")

<
This loads `zimablue-pool`.

===============================================================================
CUSTOMIZATION                                           *zimablue-customization*

Style overrides: >lua

  require("zimablue").setup({
    styles = {
      comments = { italic = true },
      keywords = { italic = true },
      functions = { bold = true },
      variables = {},
    },
  })

<
Color and highlight callbacks: >lua

  require("zimablue").setup({
    on_colors = function(colors)
      colors.zima_blue = "#16B8F3"
    end,
    on_highlights = function(highlights, colors)
      highlights.Normal = { fg = colors.fg, bg = colors.bg }
    end,
  })

<
The on_highlights callback receives the generated highlight table before any
groups are applied, so existing groups can be inspected or overridden.
